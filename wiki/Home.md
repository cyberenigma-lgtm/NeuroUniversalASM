## 🎯 What is NUASM?

NUASM (Neuro-Universal-ASM) is the world's first native multi-language assembler that lets you write x86-64 assembly code in **51 different languages**.

### Key Features
- ✅ 51 languages supported
- ✅ Zero transpilation (direct to machine code)
- ✅ Kids Mode for learning
- ✅ 100% compatible with MultiLang-ASM
- ✅ No external dependencies

## 📖 Getting Started

```bash
# Install
git clone https://github.com/cyberenigma-lgtm/Neuro-OS-Genesis
cd Neuro-OS-Genesis/Neuro-Universal-ASM

# Compile your first program
python src/unasm.py examples/test_es.asm -l es -o program.bin
```
