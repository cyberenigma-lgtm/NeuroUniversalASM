# 🧸 Kids Mode

**Learn assembly programming with simple, friendly words**

---

## What is Kids Mode?

Kids Mode uses **easy-to-understand words** instead of technical terms:

| Instead of... | Use... | Meaning |
|---------------|--------|---------|
| `mov` | `put` | Put a value |
| `add` | `add` | Add numbers |
| `sub` | `take` | Take away |
| `syscall` | `show` | Show result |
| `ret` | `return` | Go back |

---

## 🎯 Your First Program

```asm
; My first program
put number, 5
add number, 3
show
return
```

**What it does**: Puts 5 in a box, adds 3, shows the result (8)
